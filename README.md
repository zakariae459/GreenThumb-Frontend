# GreenthumbAPP
Projet d'application web pour 2eme année de génie informatique
Interface utilisateur React pour l’application GreenThumb.

---

## Prérequis

- Node.js (v16 ou supérieure recommandée)  
- npm (fourni avec Node.js)  

---

## Installation

1. **Cloner le dépôt**

```bash
git clone https://github.com/zakariae459/GreenThumb-Frontend.git
cd GreenThumb-Frontend

Installer les dépendances:
npm install

Lancement de l’application:
npm start
